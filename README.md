# 🚀 Sprint 7 — Автоматизированные тесты API Яндекс.Самокат

Этот репозиторий содержит автотесты REST API для сервиса Яндекс.Самокат.  
Тесты написаны с использованием **Java 11**, **JUnit4**, **RestAssured** и **Allure**.

---

## 📦 Состав проекта

- `src/test/java/scooter/test/` — модульные тесты для API ручек:

  | Класс                  | Описание                                   |
    |------------------------|--------------------------------------------|
  | `CreateCourierTests`   | Тесты создания курьера                     |
  | `LoginCourierTests`    | Тесты авторизации курьера                  |
  | `CourierDeleteTests`   | Тесты удаления курьера                     |
  | `OrderTests`           | Тесты создания заказа                      |
  | `OrderListTests`       | Тесты получения списка заказов            |
  | `OrderTrackTests`      | Тесты получения заказа по его трек-номеру |
  | `OrderAcceptTests`     | Тесты принятия заказа курьером (параметризованные) |

- `src/test/java/scooter/client/` — REST-клиенты, инкапсулирующие работу с API:

  | Класс            | Описание                          |
    |------------------|-----------------------------------|
  | `CourierClient`  | Методы для работы с курьером      |
  | `OrderClient`    | Методы для работы с заказами      |

- `src/test/java/scooter/model/` — модели данных (POJO):

  | Класс         | Описание                                 |
    |---------------|------------------------------------------|
  | `OrderModel`  | Тело запроса на создание заказа          |

- `src/test/java/scooter/config/` — общие настройки:

  | Класс       | Описание                                     |
    |-------------|----------------------------------------------|
  | `BaseSpec`  | Спецификация RestAssured для всех запросов   |

- `target/allure-results/` — результаты выполнения тестов (JSON-файлы для Allure)

## ✅ Что покрыто

- 🛵 Курьер:
  - Создание нового курьера
  - Логин курьера
  - Удаление курьера

- 📦 Заказ:
  - Создание заказа с параметрами (цвет, комментарий, дата)
  - Получение заказа по трек-номеру
  - Получение списка заказов:
    - без параметров
    - по `courierId`, `nearestStations`
    - с лимитом и пагинацией
  - Принятие заказа курьером

- 🔍 Проверки:
  - Позитивные сценарии (валидные данные)
  - Негативные сценарии:
    - Отсутствие обязательных полей (400)
    - Неверные данные (404)
    - Повторное создание с тем же логином (409)
  - Параметризованные тесты:
    - Невалидные ID при принятии заказа
